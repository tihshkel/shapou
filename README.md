## 📖 Описание

**ShaPou** — это современное iOS-приложение, разработанное на SwiftUI, которое позволяет вам заботиться о виртуальном питомце. Игра сочетает в себе элементы тамагочи с интерактивными мини-играми, создавая увлекательный опыт взаимодействия с вашим цифровым другом.

Ваш питомец ShaPou нуждается в постоянной заботе: его нужно кормить, играть с ним, следить за его эмоциональным состоянием и чистотой. Приложение включает систему отслеживания различных параметров питомца и несколько увлекательных мини-игр.

## ✨ Возможности

### 🎮 Основной функционал
- **Интерактивный виртуальный питомец** — живой персонаж с различными состояниями и эмоциями
- **Система отслеживания состояния** — мониторинг голода, эмоций и чистоты питомца
- **Динамические эмоции** — питомец реагирует на ваши действия и меняет свое настроение

### 🎨 Интерфейс
- **Современный дизайн** — красивый и интуитивный пользовательский интерфейс на SwiftUI
- **Адаптивная верстка** — оптимизация для различных размеров экранов iOS
- **Визуальная обратная связь** — анимации и переходы для улучшения пользовательского опыта

### 🎯 Мини-игры
- **Кухонная игра** — готовьте еду для вашего питомца
- **Игра с мытьем** — поддерживайте чистоту ShaPou
- **Игра на прогулке** — развлекайте питомца на свежем воздухе

### 🎵 Аудио
- **Фоновая музыка** — приятное музыкальное сопровождение
- **Управление звуком** — настройка громкости и контроль воспроизведения

## 🚀 Установка

### Требования

- **iOS** 15.0 или выше
- **Xcode** 14.0 или выше
- **Swift** 5.7 или выше
- **macOS** для разработки

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/tihshkel/shapou.git
   cd shapou
   ```

2. **Откройте проект в Xcode**
   ```bash
   open ShaPou.xcodeproj
   ```

3. **Настройте проект**
   - Выберите команду разработки в настройках проекта (Signing & Capabilities)
   - Убедитесь, что все ресурсы добавлены в Target

4. **Запустите приложение**
   - Выберите целевое устройство или симулятор
   - Нажмите `⌘R` или кнопку Run в Xcode

### Сборка из командной строки

```bash
xcodebuild -project ShaPou.xcodeproj -scheme ShaPou -sdk iphonesimulator -destination 'platform=iOS Simulator,name=iPhone 15'
```

## 🛠 Технологии

Проект построен с использованием современных технологий Apple:

| Технология | Описание |
|------------|----------|
| **[SwiftUI](https://developer.apple.com/xcode/swiftui/)** | Декларативный фреймворк для создания пользовательского интерфейса |
| **[AVFoundation](https://developer.apple.com/av-foundation/)** | Фреймворк для воспроизведения музыки и звуковых эффектов |
| **[UIKit](https://developer.apple.com/documentation/uikit)** | Используется для некоторых системных компонентов и интеграций |

### Архитектурные решения

- **Singleton Pattern** — `MusicManager` для управления аудио
- **State Management** — использование `@State` и `@Binding` для управления состоянием
- **MVVM Architecture** — разделение логики и представления

## 🎮 Использование

После запуска приложения:

1. **Взаимодействие с питомцем** — нажимайте на различные кнопки для взаимодействия
2. **Следите за показателями** — обращайте внимание на иконки состояния (голод, эмоции, чистота)
3. **Играйте в мини-игры** — используйте специальные кнопки для запуска игр
4. **Наслаждайтесь музыкой** — фоновая музыка создает атмосферу
